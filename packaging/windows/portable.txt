PdfZ portable mode

While this file sits next to pdfz.exe, PdfZ keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfZData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PdfZ with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\PdfZ and
%LOCALAPPDATA%\PdfZ) instead. If PdfZData can't be written (for example on a read-only
drive), PdfZ says so and uses the per-user folders instead.
